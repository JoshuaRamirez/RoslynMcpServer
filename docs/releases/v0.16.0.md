# Release Notes — `v0.16.0` (2026-11-02)

## Highlights

`RoslynMcpServer v0.16.0` delivers the 5-Layer Action Algebra (`TargetCoordinate`, `SymbolPredicate`, Warm `SolutionSessionManager` + Atomic `SolutionTransaction`, `CodeActionHost` / `SyntaxGenerator` / `IOperationSemanticRewriter`, and Compact `$defs` MCP Schema) across `RoslynMcp.Contracts`, `RoslynMcp.Core`, `RoslynMcp.Server`, and `RoslynMcp.Cli`.

## What's New

1. **Layer 1 — `TargetCoordinate` (`DocumentScope × Anchor × EnclosingNormalization`)**:
   - Universal targeting across `FilePaths`, `ProjectNames`, and `DirectoryGlobs` combined with `LineSpan`, `TextSpan`, `SymbolPath`, or `SyntaxIndex` anchors and `Exact`, `EnclosingStatement`, `EnclosingBlock`, `EnclosingMember`, or `EnclosingType` normalization.
2. **Layer 2 — `SymbolPredicate` AST & `SymbolPredicateEvaluator`**:
   - Composable boolean AST (`All`, `Any`, `Not`) over `SymbolKindIn`, `AccessibilityIn`, `NameMatches`, `NamespaceMatches`, `HasAttribute`, `ImplementsOrInherits`, `CallerCountRange`, `ReferencesCountRange`, and `InDocumentScope`.
3. **Layer 3 — Warm `SolutionSessionManager` & Atomic `SolutionTransaction` (`roslyn_transaction`)**:
   - Persistent in-memory `WarmSolutionSession` with incremental `WithDocumentText` updates (`<50 ms` warm turnaround), sequential operation folding, `PreviewDiffOnly` unified diff output, and `RollbackOnCompilationErrors` atomic rollback.
4. **Layer 4 — `CodeActionHostRunner`, `SyntaxGeneratorRunner` & `IOperationSemanticRewriter`**:
   - Diagnostic-driven code fixes, structured `SyntaxGenerator` declaration synthesis/modification, and `IOperation`-verified semantic rewrites (`ConvertForeachToLinq`, `ConvertIfToSwitchExpression`, `ConvertToPatternMatching`, `ConvertToInterpolatedString`, `ConvertExpressionToBlockBody`, `ConvertBlockToExpressionBody`, `AddNullChecks`, `InvertIf`).
5. **Layer 5 — Compact `$defs` MCP Tools (`roslyn_transaction`, `roslyn_query_symbols`) & CLI (`transaction`, `query-symbols`)**:
   - Shared JSON Schema `$defs` in `CompactSchemaDefs` and full CLI parity (68 tools total).

## Verification

- Verified `0` compiler errors and `0` warnings across `RoslynMcp.sln`.
