# Release Notes — `v0.17.0` (2026-11-25)

## Highlights

Bug-fix and hardening release for `RoslynMcpServer`: refactoring-tool correctness fixes, `sealedFilter` for `get_symbol_info`, and a faster Linux-only PR CI with nightly full matrix. See `CHANGELOG.md` for full details.

## Merged changes since v0.16.0

- generate_overrides / implement_abstract: copy nullable flow attributes onto overrides (#3401) (#3469)
- generate_equals_hashcode: compare dynamic members through EqualityComparer<object> (#3374) (#3468)
- change_signature: reject single-site rewrite of interface member declarations (#2966) (#3452)
- ci: fast Linux-only PR/push CI (sharded tests, NuGet cache) + nightly full 3-OS matrix (#3473)
- find_references / find_callers: kindFilter judges auto-property and event initializers as Property/Event (#2956) (#3456)
- generate_method_stub: emit static stub for calls in local functions of static members (#2950) (#3454)
- remove_unused_usings: keep live usings whose names carry embedded trivia (#2946) (#3455)
- safe_delete: reject same-line empty selection with InvalidSelectionRange (#387) (#3448)
- fix: convert_tuple_to_struct refuses by-ref element uses when asRecord is false (#3347) (#3441)
- generate_property / extract_constant: refuse "_" as the new name so existing discards don't bind to it (#3301) (#3440)
- fix: extract_method refuses methodName "_" so existing discards don't bind to the new method (#3299) (#3439)
- generate_method_stub: refuse var deconstruction targets instead of emitting var in the return type (#3403) (#3438)
- invert_if: don't flip relational ops lifted to T? through an implicit conversion (#3426) (#3437)
- fix: extract_variable refuses special min-value unary operand (#3355) (#3436)
- extract_variable: keep separating space before is/as/switch/with (#3295) (#3435)
- Accept explicit void returnType in generate_method_stub (#3404) (#3434)
- fix: inline_constant NaN/Infinity → legal double/float member access (#1985) (#3433)
- Keep the sign of a negative-zero decimal in inline_constant (#3423) (#3431)
- Honor get_symbol_info optional sealedFilter (#3356) (#3357)
