# Release Notes — `v0.17.0` (2026-11-25)

## Highlights

Bug-fix and hardening release for `RoslynMcpServer`: refactoring-tool correctness fixes, `sealedFilter` for `get_symbol_info`, and a faster Linux-only PR CI with nightly full matrix. See `CHANGELOG.md` for full details.
